# 🎮 Student Game Hub

A Python desktop application that brings together four mini-games in one graphical interface.

## 🕹️ Games Included

- **Guess the Number:** Guess a randomly generated number between 1 and 100.
- **Rock Paper Scissors:** Play against the computer and compete to reach five points.
- **Hangman:** Guess the hidden word one letter at a time.
- **Snake Game:** Control the snake using the keyboard arrow keys.

## 🛠️ Technologies Used

- Python
- Tkinter — graphical user interface
- Turtle — graphics for the Snake game
- Random — random numbers and game choices
- Threading — running the Snake game in a separate thread

## ✨ Features

- Interactive graphical interface
- Multiple games in one application
- Score tracking in Rock Paper Scissors
- Custom colors and a starry background

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python game_hubpy.py
```

**Note:** Tkinter and Turtle are included with many standard Python installations. Availability may depend on your Python setup.
